# Process, extended

Extra rules for planning, on top of `docs/PROCESS.md`. Where the two differ, follow this file.

## Planning

When you write a plan, as in "Please plan the pilot":

1. **Label your own choices.** Start the plan with a "Choices for you" list. It holds every decision
   the documents in `docs/` don't make, each with one line on why. The student reviews these first.
2. **Cap the size.** Give each phase at most 8 success criteria. If a phase needs more, split it into
   two phases.
3. **Name a backup browser check.** Say which tool checks pages in the browser. If the Playwright MCP
   server isn't connected, name the tool used instead, such as the Chrome DevTools MCP server.
